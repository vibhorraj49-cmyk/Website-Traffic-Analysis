# Website Traffic Analysis

## Project Overview
This project analyzes website traffic logs to understand user behavior, traffic trends, top-performing content, and engagement patterns.

The analysis helps identify:
- Top countries and cities generating traffic
- Popular artists, albums, and tracks
- Daily traffic trends
- User engagement behavior
- Optimization opportunities for Alfido Tech

---

## Dataset
Dataset Source:
https://www.kaggle.com/datasets/bhanupratapbiswas/website-traffic-analysis

---

## Objectives
- Analyze website traffic logs
- Understand user journeys
- Identify top landing pages
- Analyze engagement patterns
- Visualize traffic trends
- Provide optimization recommendations
